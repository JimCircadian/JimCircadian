Welcome to the personal Github home of James Byrne, previously Digital Research Compute Lead at the University of Exeter. I used to work at the [British Antarctic Survey](https://www.bas.ac.uk), so have a computational domain interest leaning towards the environmental sciences. Previously I worked for industry in various forms, but that's long behind me...

I work on tools and systems that underpin Digital Research Infrastructure. On GitHub you'll find tools that I use to maintain or run servers. 

[My personal self-hosted website is called Inconsistent Records](https://inconsistentrecords.co.uk). There is an [RSE community oriented profile over at the Software Sustainability Institute](https://www.software.ac.uk/about/fellows/james-byrne) or [my ORCID](https://orcid.org/0000-0003-3731-2377) for more research related bits I've been involved with.

Pretty soon I'll be looking at migrating new and old projects (that can stand it) off to [Codeberg](https://codeberg.org). [There's good treatment of the arguments against GitHubs vendor lock practices at the Software Conservancy](https://sfconservancy.org/GiveUpGitHub/). 

Thanks for dropping by 🎉
